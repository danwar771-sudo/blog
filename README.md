# Vice Garage

Diario visual del proyecto para el GTA Car Render Challenge 2026.

## Publicación

El sitio es estático y puede publicarse directamente con GitHub Pages. No requiere instalación de dependencias ni proceso de compilación.

## Estructura

- `index.html`: portada, misión y tarjetas WIP.
- `styles.css`: sistema visual responsive.
- `script.js`: interacciones mínimas de las entradas pendientes.
- `assets/`: renders y capturas del proceso.
